# Режим арены в wega-mega

Этот документ — краткий обзор дуэльной/аренной подсистемы в `wega-mega`, а также выводы из изучения аналогичных реализаций в смежных билдах.

## Что есть в wega-mega сейчас

### Базовый дуэльный режим
- **Система**: `Content.Server/_Wega/Duel/Systems/DuelArenaSystem.cs`
- **Компонент**: `Content.Server/_Wega/Duel/Components/DuelArenaComponent.cs`
- **Прототип**: `DuelArenaTracker`
- **Механика**: по сигналу `Open` трекер регистрирует живых бойцов в зоне, стартует бой, ждёт, когда один из бойцов упадёт в крит/смерть, после чего объявляет победителя, исцеляет участников, чистит арену и восстанавливает стены.
- **Связанные системы**:
  - `DuelArenaCleanupSystem` — уборка выданного снаряжения, гильз, луж, мусора.
  - `DuelArenaRestoreSystem` — снапшот и восстановление стен, решёток, света.
  - `DuelReadySystem` — кнопки готовности для обеих баз.
  - `DuelRotationSystem` — предзагрузка нескольких арен и перемещение бойцов между раундами.
  - `DuelArenaScoreSystem` — счёт побед/поражений и серии по `NetUserId`, табло в анонсе итога боя.
  - `ArenaArsenalRemoteSystem` — пульт арсенала: UI-выбор тира арсенал-крейта, применяется ко всем аренам разом; сами крейты у спавн-маркеров каждый раунд спавнит `DuelArenaSystem` (EnsureArsenalCrates).

### Окружение и события
- `ArenaStormSystem` — сужающаяся «безопасная зона» (battle-royale), наносит урон за пределами круга.
- `ArenaAirstrikeSystem` — периодические авиаудары по случайным тайлам в радиусе живых бойцов, с предупреждающим маркером.
- `RandomWeaponGiftSystem` — дроп случайного оружия.
- `ArenaHarpoonSystem` — арбалет/гарпун, притягивающий цель.

### Недавние улучшения
- **Таймер раунда убран**: дуэль идёт до реальной победы или ручного сброса; ничьей по таймауту и фазы «внезапной смерти» больше нет (поля maxFightDuration/suddenDeathDuration удалены из DuelArenaComponent — не задавайте их в прототипах трекеров). Шторм сужается по собственному `startDelay` (ArenaStorm), у босс-арены свой независимый MaxFightDuration.
- **PvE-босс-арена**: по сигналу `Open` собирает участников, телепортирует их, спавнит босса, отслеживает его фазы, выдаёт награду при смерти босса или сбрасывается при поражении участников.

### Вспомогательные системы, пригодные для арены
- `RaidControllerSystem` — загрузка отдельной карты, телепортация игроков, награды при эвакуации, очистка инстанса.
- `RaidLootFieldSystem` / `RaidLootSpawnerSystem` — расстановка случайного лута/врагов на карте.
- Megafauna (Лаваленд) — готовые босс-мобы с фазами, музыкой, ачивками и наградами.
- `Content.Server/_Wega/Magic/` — заклинания, которые можно использовать как способности босса или игрока.

## Что показали другие билды

### Goob-Station-Corvax — Thunderdome
- Гост-доступная арена: госты могут зайти во временное тело, подраться и вернуться в оригинальное.
- UI выбора лодаута по категориям (Shotguns, SMG, Rifles, Melee...).
- Трекер убийств/смертей, серии убийств (kill streaks).
- Временное тело удаляется при выходе/смерти; оригинальное тело сохраняется.
- Можно взять: категорийный UI лодаута, статистику, гост-арену.

### ss220 — Arena
- Полноценная арена с лобби:
  - Фазы: Waiting, Countdown, Fight, Reset.
  - Таймер боя и таймаут.
  - Команды и командные бои.
  - Ротация карт (случайная/по очереди).
  - Статусные иконки и EUI для участников.
- Можно взять: фазовую машину, лобби, ротацию карт, систему очков.

### arcane-station / lust-station — PvE-босс-арена
- Инстанс-карта: игроков телепортирует в отдельную арену, после боя возвращает.
- Босс с фазами, PvE-энкаунтер.
- Очистка карты между заходами.
- Можно взять: инстансирование, возврат игроков, PvE-фазы.

## Идеи для дальнейшего развития

1. **Система очков и стриков** — победы/поражения/ничьи по `NetUserId`, таблица лидеров, награды за серию побед.
2. **Категории лодаута** — UI выбора оружия перед боем (как в Goob Thunderdome).
3. **Лобби и ротация арен** — очередь игроков, таймер до старта, автосмена карты.
4. **Гост-арена / Thunderdome** — временные тела для гостов, сохранение оригинального тела, возврат после боя.
5. **События по таймеру** — привязка аирстрайков, дропов, анонсов к фазам боя.
6. **PvE-босс-арена v2** — перенос на отдельную инстанс-карту, волны миньонов, уникальные способности босса, ачивки.
7. **Магазин наград** — валюта арены для покупки лодаутов/оружия между раундами.
