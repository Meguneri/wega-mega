# Пульт арсенала арены — концепты иконки

Наработка: 4 варианта иконки для `ArenaArsenalRemote`, сгенерированы пиксель-арт скриптами (`gen.py` в каждой папке, Python + Pillow).

- **selektor** — Роторный селектор — ВЫБРАН как рабочий спрайт пульта.
- **krejt-fob** — Мини-ящик снабжения на рукояти с курком.
- **mayak-snabzheniya** — Армированный короб с антенной, дисплей + тир-LED.
- **datapad** — Плоский планшет с крейт-глифом и тир-баром.

Финальный рабочий спрайт: `Resources/Textures/_Wega/Objects/Devices/arena_arsenal_remote.rsi` (селектор + свои инханды).
