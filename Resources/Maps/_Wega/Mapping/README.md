# Пользовательские карты для маппинга

Сохранены при экспорте действующего сервера 25 октября 2026:

- `NEWMAP.yml` — последняя доступная автокопия исходной карты NEWMAP;
- `../Arena/Adelin_Penthouse.yml` — вручную сохранённый Adelin Penthouse.
- `../Arena/Adelin_Penthouse_v2.yml` — актуальная версия от arhont1234,
  сохранённая 25 октября 2026 в 23:12 по Волгограду и включённая в снимок
  для следующего развёртывания 26 октября. Исходное сохранение перенесено без изменений.

Это карты для загрузки в режиме маппинга, а не новые станции в случайной ротации.
Полная история автосохранений и более поздние автокопии Adelin хранятся отдельно
в приватном `userdata.tar.gz` комплекта переезда. Геометрия при импорте сохраняется;
исправляются только недопустимые варианты тайлов, если они есть.
